Before testing

Both devices need internet and must open this page over HTTPS in a current browser. PeerJS provides signaling and WebRTC attempts a direct video connection. Some mobile networks and Wi-Fi routers require a TURN relay; this standalone file does not include TURN credentials, so connectivity cannot be guaranteed on every network.

If the connection ID does not appear, check that the PeerJS script loaded and that the network permits access to PeerJS signaling. Never share a connection ID publicly.
